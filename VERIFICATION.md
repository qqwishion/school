# Проверка реализации

Дата: 8 ноября 2026. Среда: Windows, Python 3.14.10, Django 5.2.19. Проверены SQLite и отдельный локальный PostgreSQL 17.11. Страница проекта доступна после `start.cmd` на `http://127.0.0.1:8000/materials/`.

## Выполнено

- Миграции с нуля на обеих базах.
- Django system check: ошибок нет.
- `makemigrations --check --dry-run`: незаписанных изменений моделей нет.
- 19 автоматических серверных тестов проходят на обеих базах.
- `check --deploy` с production-настройками: ошибок и предупреждений нет. Это проверка конфигурации; публичный HTTPS-сервер не разворачивался.
- Созданы резервные копии SQLite и PostgreSQL вместе с файлами. Дамп PostgreSQL успешно восстановлен в отдельную базу `shag_restore_check`: 18 материалов и 18 вложений.
- Браузерный сценарий Playwright с установленным Edge: прошёл с SQLite и PostgreSQL. JavaScript-ошибок нет. Проверены каталог, кириллический поиск, совместные фильтры, возврат с сохранением URL, мобильные фильтры, регистрация с настоящими CSRF-cookie, избранное, выход и клавиатурный переход к содержимому.
- Ширины 1440 и 360 px. Горизонтальная прокрутка отсутствует в каталоге, материале, входе, регистрации и странице «О проекте». Скриншоты: `artifacts/catalog-desktop.png`, `artifacts/catalog-mobile.png`, `artifacts/material-mobile.png`; машинный результат: `artifacts/browser-results.json`.
- В базе 18 демонстрационных заданий, по три на направление; у каждого есть PDF. Повторная команда seed не создаёт дубликатов и не перезаписывает правки.

## Что требует участия человека или инфраструктуры

1. Педагогическая редактура всех заданий и PDF. Фамилии проверяющих и результаты испытаний не выдумывались. Тестовая строка проверяющего существует только во временной тестовой базе, которая удаляется после тестов.
2. Создание администратором собственного аккаунта командой `createsuperuser`.
3. При публичном размещении: домен, TLS, production-секрет, PostgreSQL с защищённым доступом, настройка reverse proxy и резервных копий. Пример настроек включён в проект.
4. При школьном пилоте желательно испытание с педагогом и пользователями вспомогательных технологий.

Sites не использовался для хостинга: его Worker-окружение не исполняет выбранный Django/WSGI-сервер. Подготовлен локальный запуск, предусмотренный ТЗ.
